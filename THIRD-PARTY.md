# Third-party components

What this package ships, and where each piece comes from:

## Bundled in this package

### `bin/tts-server.exe` — build of qwentts.cpp (omnivoice.cpp)

Pre-built Windows binary of <https://github.com/ServeurpersoCom/qwentts.cpp>
("omnivoice.cpp"), used as the GPU voice server by the `qwen3` engine.

- License: **MIT** — Copyright (c) 2023-2026 The omnivoice.cpp authors.
- The full license text is in the vendored source at
  `tools/qwentts.cpp/LICENSE` of the TTSTT project; the short form is:
  the software may be used, copied and redistributed, provided the copyright
  and permission notice are included.

### `ref_voices/` — synthetic reference clips

- `pocket.wav` / `pocket.txt` — an 8 s take of the Pocket TTS voice
  (Kyutai `pocket-tts`, MIT) synthesising its own transcript. No real
  person's voice.
- `warm_brit.wav` / `warm_brit.txt` — an 18 s take of a *designed*
  voice (Qwen3-TTS VoiceDesign, Apache-2.0; the model invents the voice,
  it does not clone a person) synthesising its own transcript.

Both clips were generated by the models above and are redistributed here
under the MIT license of this package.

### Code

- `src/`, `lib/`, `tts/` — original code for this plugin (MIT), plus a
  fork of `@deepseek-ai/dsh-experimental-client-ui-voice-input`
  0.1.7-rc.2 (DeepSeek, MIT).

## Not bundled (fetched at setup, for the record)

- **Qwen3-TTS 1.7B models** (`qwen-talker-1.7b-base-Q8_0.gguf`,
  `qwen-tokenizer-12hz-Q8_0.gguf`) — Apache-2.0. Downloaded by the user on
  consent into `~/.dsh/voice-chat/models/qwen3`, not shipped.
- **Pocket TTS** (Kyutai, `pocket-tts` on PyPI / Hugging Face) — the CPU
  voice; installed with pip and its model weights download from
  Hugging Face on first use, not shipped.
- **SenseVoice STT models** — come with the official
  `@deepseek-ai/dsh-experimental-*speech-to-text*` packages installed by
  the DSH profile, not with this package.

## Deliberately excluded

- `ref_voices/british_p225.wav` (former VCTK p225 sample) was removed:
  VCTK is licensed for non-commercial research use only and must not be
  redistributed. No engine in this package references it.
